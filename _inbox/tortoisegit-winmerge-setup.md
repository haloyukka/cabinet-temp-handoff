# TortoiseGitの差分・マージツールをWinMergeに変更する手順書

## 目的と前提条件

TortoiseGitで「差分」「マージ（競合の解消）」を実行したときに、既定のTortoiseGitMergeではなくWinMergeが起動するように設定する。所要時間は5分程度。

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11 |
| TortoiseGit | インストール済み（日本語化されていること） |
| WinMerge | 2.16以降（3-wayマージを使う場合は必須） |
| 権限 | 一般ユーザーで可（設定はユーザー単位で保存される） |

## 事前準備：WinMergeの実行ファイルの場所を確認する

設定ではWinMergeU.exeのフルパスを指定するため、先に実際の場所を確認しておく。

1. WinMergeが未インストールの場合は、[WinMerge公式サイト](https://winmerge.org/)からインストーラーを入手してインストールする。
2. エクスプローラーで以下の場所を順に開き、`WinMergeU.exe` があるフォルダを確認する。
   - `C:\Program Files\WinMerge\`（64bit版・全ユーザー向け）
   - `C:\Program Files (x86)\WinMerge\`（32bit版）
   - `%LOCALAPPDATA%\Programs\WinMerge\`（ユーザー単位インストール）
3. 見つけたファイルをShiftキーを押しながら右クリックし、「パスのコピー」でフルパスを控えておく。

以降の手順では `C:\Program Files\WinMerge\WinMergeU.exe` を例に記載する。場所が異なる場合は読み替える。

## 手順1：差分ビューアーをWinMergeに設定する

1. エクスプローラーで任意のフォルダを右クリックし、「TortoiseGit」→「設定」を選ぶ。
   - Windows 11では、先に「その他のオプションを確認」を選ぶとTortoiseGitのメニューが表示される。
2. 設定画面の左ツリーで「差分ビューアー」を選ぶ。
3. 右側の「差分ビューアーの設定」で「外部」を選ぶ。
4. 入力欄に以下のコマンドを貼り付ける。

```
"C:\Program Files\WinMerge\WinMergeU.exe" -e -u -dl %bname -dr %yname %base %mine
```

5. 「適用」を押す（手順2も続けて行う場合は、画面はまだ閉じない）。

パスにスペースが含まれるため、実行ファイルのパスは必ず `"` で囲む。

## 手順2：マージツールをWinMergeに設定する（任意）

競合解消もWinMergeで行いたい場合のみ実施する。WinMerge 2.16以降の3-wayマージ（左：相手、中央：共通の祖先、右：自分）を使う。

1. 設定画面の左ツリーで「差分ビューアー」を展開し、「マージツール」を選ぶ。
2. 「外部」を選ぶ。
3. 入力欄に以下のコマンドを貼り付ける。

```
"C:\Program Files\WinMerge\WinMergeU.exe" -e -u -dl %tname -dm %bname -dr %yname %theirs %base %mine -o %merged
```

4. 「OK」を押して設定画面を閉じる。

WinMergeでマージ後に保存すると、結果が `%merged`（作業ツリーの対象ファイル）に書き込まれる。保存後、TortoiseGitで「解決済み」にする操作は従来どおり必要。

## 動作確認

- [ ] Gitリポジトリ内のファイルを1行変更して保存する
- [ ] そのファイルを右クリックし、「TortoiseGit」→「差分」を選ぶ
- [ ] WinMergeが起動し、左に変更前（ベース）、右に変更後（作業ツリー）が表示される
- [ ] ペインのタイトルにファイル名が表示されている（`-dl` / `-dr` が効いている）
- [ ] Escキーでウィンドウが閉じる（`-e` が効いている）
- [ ] 「ログを表示」からコミット同士を比較しても、WinMergeで開く
- [ ] 確認後、テスト用の変更を「元に戻す」で取り消す

## オプション・パラメータ解説

### WinMergeのオプション

| オプション | 意味 |
| --- | --- |
| `-e` | Escキーでウィンドウを閉じられるようにする |
| `-u` | 比較したファイルを「最近使った項目」に残さない |
| `-dl` | 左ペインのタイトル |
| `-dm` | 中央ペインのタイトル（3-wayのみ） |
| `-dr` | 右ペインのタイトル |
| `-o` | マージ結果の保存先 |
| `-wl` / `-wr` | 左／右ペインを読み取り専用にする（必要に応じて追加） |

### TortoiseGitが渡す変数

| 変数 | 中身 |
| --- | --- |
| `%base` | 比較元のファイル（差分：変更前、マージ：共通の祖先） |
| `%mine` | 自分の作業ファイル |
| `%theirs` | 相手側（マージ対象ブランチ）のファイル |
| `%merged` | マージ結果を書き込む作業ツリー上のファイル |
| `%bname` / `%yname` / `%tname` | 上記それぞれの表示用の名前 |

## トラブルシューティングと元に戻す方法

| 症状 | 確認・対処 |
| --- | --- |
| 差分を開いてもTortoiseGitMergeが起動する | 「外部」が選ばれているか、「適用」「OK」で保存したかを確認する |
| 「ファイルが見つかりません」と出る | WinMergeU.exeのパスが実際の場所と一致しているか、`"` で囲んでいるかを確認する |
| WinMergeは起動するが片側が空になる | 変数の綴り（`%base` `%mine` など）と、変数の間のスペースを確認する |
| 3-wayマージにならない | WinMergeのバージョンが2.16以降かを確認する（「ヘルプ」→「WinMergeについて」） |
| マージ結果が反映されない | WinMergeで保存してから閉じたか、保存先に `-o %merged` を指定したかを確認する |

### 一時的に既定ツールを使う

Shiftキーを押しながら右クリックメニューの「差分」を選ぶと、設定を変えずにTortoiseGitMergeで開ける。

### 設定を元に戻す

1. 「TortoiseGit」→「設定」→「差分ビューアー」を開く。
2. 「TortoiseGitMerge」を選び直す（マージツールも同様）。
3. 「OK」を押す。
